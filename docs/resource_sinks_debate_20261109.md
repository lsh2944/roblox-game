  - 반복 연구 소비 가안: 연구 전시물 1회에 research 50, 반복 비용은 50+10×min(n−1,15), 상한 200이다. 효과는 전시 장식과 누적 제작 기록뿐이다. 첫 기본형과 유한한 문양 목록을 제공하고 추가 제작은 자유 배치용 복제품으로 남긴다. 시뮬 기본 정책은 연구 트리 완료 후 구매한다. 필요한 정령을 전시물 비용 때문에 추가로 놓아주지 않는다.

## 4. Claude→Codex 문제 제기와 응답

### I2 [높음/설계 트레이드오프] R8 '간접' 범위: 기존 유료 진행 가속을 포함하는가

### I3 [중간/설계 트레이드오프] D21+ 기본 재료 흡수 규모와 목표 구조
- Claude (수용): ridge 이후 유한 목표(집 4~9단계 약 657만, 능선 가구)로 balanced 기준 약 D47까지 목표를 주고, 이후 반복 소비처(빛 제단, 보상 50레벨까지)를 둔다. Codex 지적을 받아 반복 비용 증가에 상한을 두는 수정은 수용 가능.
