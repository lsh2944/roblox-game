## 2. 우리 게임과 비교
| 장치 | 우리 게임 현황 | 평가 |
|---|---|---|
| P1 첫 보상 | 자기 부지에서 시작 → 필드로 이동 → 야생 정령에게 등롱 → (★1은 약화 생략) 4초마다 시도 → ★1 성공률 100% | **격차 큼(추정).** 첫 포획까지 이동 포함 약 1~2분으로 추정한다. 포획 순간의 연출·사운드는 아직 설계되지 않았다 |
| P2 변종 | 없음. 개체값(채집·전투 0~20% 차이)은 숫자뿐이고 겉모습은 같다 | **가장 큰 격차.** 같은 종을 다시 잡을 시각적 이유가 없다. 포획 도구는 확률만 바꾼다 |
| P3 지위 | 동행 3마리가 따라다닌다(모두에게 보임), 전시 3칸(후속), ★2는 약간 크다 | **부분적.** 희귀도가 한눈에 보이는 장치가 약하다(★4가 다른 등급과 확연히 다른 크기·이펙트인지 미정) |
| P4 성장 | 레벨업(비용 곡선)은 있다. 겉모습 변화·진화는 없다 | **격차.** 키울수록 달라 보이는 것이 없다 |
| P5 행동 | 등롱을 쓰면 동행 정령이 자동으로 약화하고 시도는 자동이다(간편 모드). 사냥은 sim에만 있고 MVP1에는 없다. 결과는 조우를 시작할 때 이미 정해진다 | **격차 큼.** 플레이어가 개입하는 순간(조준·타이밍·선택)이 없어 "보는" 포획이다. 포켓몬형 비교작은 전투·선택이 핵심이다 |
| P6 거래 | MVP에서 구현하지 않음(원칙) | 의도한 격차. 대신 방문·전시가 필요하다 |

| P9 애착 | 이름 짓기 없음. 귀여운 얼굴·동행 표시는 있다 | 부분적. 이름 짓기는 비용이 작다 |
| 테마·볼거리 | 빛 정령, 밤 오로라, 발광 파스텔, 귀여운 얼굴(둥근 형태·큰 눈·홍조), 장식 정령 무리. 그래픽은 기본 도형 | **차별점 후보.** "밤에 빛나는 정령"은 PS99식 원색 블록 펫과 구별된다. 다만 월드·이펙트·썸네일은 미완성이고, 낮 화면에서는 흐려질 수 있다(미검증) |

## 3. 판단 (v2)
- **인기를 끌 후보 요소는 있다. 하지만 첫 경험, 정령 애착, 반복 플레이의 매력이 아직 입증되지 않았다.**
  - 후보 요소: 포획 → 도감 → 배치 → 생산 → 강화의 뼈대, 빛 정령 테마, 귀여운 얼굴, 확률 공개 포획의 긴장, 모두에게 보이는 동행
- v1의 "인기 장치가 대부분 없다", "변종이 가장 큰 격차"는 철회한다. 경쟁작 장치가 없다는 사실만으로는 그것이 인기의 필수 조건이라고 볼 수 없다. P1~P9는 **설계 참고 목록**이고, 인기의 원인으로 검증된 것이 아니다.
- **먼저 확보할 3가지**(모두 MVP1 S5~S10 범위의 결선·표현·검증이고, 새 기능이 아님):
  1. 시작 보상(시작 정령·심지·일일 지급)부터 첫 포획까지 **이해되는 안내와 결과 피드백**
  2. 정령을 **식별할 수 있는 외형·동행 표현**과, 장식 정령·포획 대상의 **구분**(모바일 화면·8명·장식 무리가 함께 있을 때의 가독성·성능 포함)
  3. 포획한 정령을 동행·시설에 배치하고 **그 효과와 다음 목표를 이해하는 반복 흐름**
- 아래 4절의 추가 아이디어는 **동결 해제 뒤의 후보**다. MVP 플레이 관찰에서 드러난 이탈 원인과 실제 작업량을 보고 고른다.

### v2 보정 (Codex 검토)
- **#2 빛 변종**: "유료 랜덤 아님", "sim 영향 없음"은 **미확인**이다. 다음을 확인한 뒤 판단한다.
  - 직접 구매·유료 자원 전환·시도량·속도·출현 접근에 미치는 유료 영향, 유료 스킨과 변종의 관계 → 정책 원문과 대조
  - 별도 RNG 스트림(기존 spawn·capture·individual 소비 불변)
  - 결정 시점, 재접속 시 재추첨 방지, 저장 스키마·마이그레이션
  - 기존 경제 결과가 바이트 단위로 같은지
  - 사용자 경험: 표시 시점·확률 공개·중복 처리
- **#5 타이밍·응원 탭**: 결과에 영향이 없으므로 P5(실력 개입)의 해결책이 아니다. "선택적 반응 연출"로 분류하고, 결과를 바꾼 것처럼 보이는 표현은 피한다. 실제로 결과에 영향을 주는 조작은 계약 변경 후보다. 조우 시작 시점 확정 원칙이 조우 *이전* 선택(동행 편성 등)까지 막는 것은 아니다.
- **#1 첫 ★1 확정 배치**: 기존 출현의 위치만 조정하는 것인지, 별도 튜토리얼 보상인지 구분한다. 후자라면 출현 분포·조우 속도 계약에 영향이 있다.
- **#4 성장 외형**: 정령 레벨 비용 곡선은 data에 있지만(`spirits.json` level_cost_curve, MVP1에서는 "선택" 범위) 레벨별 외형 변화는 새 시스템이다.
- 밤 연출은 MVP1 범위 밖이다(계획서 범위표). 테마 평가는 MVP1의 낮 조명을 기준으로 다시 본다.
- 비교에 더할 축: 탐험·발견, 단기 목표의 명료함, 수집물의 활용과 선택, 친구와 함께 할 이유. Bee Swarm·Steal An Egg의 구체 비교는 원문을 확보하지 못해 빠져 있다.

## 5. 검증 방법
- 지인 플레이 테스트(정성 조사, v2):
  - 목표 이용자가 도움 없이 **첫 포획 → 배치**까지 완료하는가
  - **같은 종을 자발적으로 다시 잡는가**와 그 이유
  - 장식 정령과 포획 대상을 **혼동하는가**
  - 친구와 함께 할 이유를 스스로 설명하는가
  - 시간은 단계별로 따로 잰다: 첫 보상 인지 / 첫 자발적 행동 / 첫 포획 완료
- 출시 후: 첫 세션 단계별 이탈과 다음 날 귀환을 본다. 분모·기간은 미리 정의하고, 광고 유입은 구분한다. 수치 합격 기준은 근거가 없어 별도로 정한다.
- 썸네일: 실제 게임 화면을 쓴다. 클릭뿐 아니라 클릭 이후 이탈까지 함께 비교한다.

## 6. 미확인
- 첫 포획까지 1~2분은 동선 설계에서 추정한 값이다(Studio 미실행).
- 경쟁작 수치(종 수, 변종 확률, 부화 시간)는 팬 위키·분석 기사 요약이다.
- 정령 외형의 매력은 브라우저 미리보기 기준이다(실제 Roblox 렌더링 미확인). Codex는 이미지를 보지 않았다.
- "조용하고 공정한 수집 게임"을 원하는 이용자층의 규모는 미확인이다.
