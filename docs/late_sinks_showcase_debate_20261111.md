## 1. 질문·요구사항

> # Brief: 후반 재료 소비(지역 재료 포획 도구·개체값 파밍)와 전시·방문·거래 원칙 (2026-11-11)

> ## 1. 질문
> 필드를 진행한 뒤 쌓이는 사냥 재료를 어떻게 소비시키고, 후반 유저의 지속 동기를 어떻게 만들까? 다음을 설계한다.
> - 지역 특수 재료(사냥 재료)로 만드는 포획 도구: 사용하면 포획 성공률이 등급별로 조금 오른다.
> - 같은 ★4 정령을 여러 마리 잡게 만드는 개체값(스탯 분포) 파밍 동기.
> - 자기 집 안에서 방치 생산 중인 정령이 움직이는 연출과, 다른 유저의 집을 방문해 보는 기능.
> - 남는 재료·정령을 유저끼리 교환·거래·전시하는 기능. 이번에는 원칙과 위험만 다룬다.
> 더 좋은 아이디어가 있으면 함께 제안한다.

## 3. Codex 제안
- 요약: 권장안은 현행 개체값 100~120%를 유지하면서 비교·전시를 강화하고, 지역 포획 보조재를 선택적 후반 소비처로 추가하는 것이다. 모든 재료를 소진시키는 목표는 두지 않는다. 같은 서버 집 방문까지 MVP로 제한하고 거래·교차 서버 방문·희귀 변종은 후속으로 둔다. 중요한 코드 사실은 meadow·forest에는 ★4가 없어 '지역 첫 ★4'를 공통 해금 조건으로 사용할 수 없다는 점, 현재 행동 정책은 개체값 반복 파밍을 직접 최적화하지 않는다는 점이다. 수치와 범위 변경은 사용자 결정 전 제안이며, 구현·시뮬·외부 변경은 실행하지 않았다.

Codex가 지적한 대로 ×1.1 일괄은 ★2에서 +7.5%p가 되는 문제가 있다. 이는 ★2 배율을 작게 두는 등급별 배율로 해결된다. 시도당 소비는 실패가 길수록 더 쓰는 구조라 '운이 나쁘면 더 낸다'는 체감이 생기고, 조우당 소비보다 비용 예측이 어렵다.

### I2 [높음/설계 트레이드오프] 도구 해금·적용 범위: 종의 고유 필드 기준 대 조우 필드 기준, 전역 ridge 해금 조건

### I3 [중간/설계 트레이드오프] 개체값 표시: 통합 등급(S/A/B) 대 축별 우수 표시
- Claude (수용): Codex 절충을 수용한다. 기본 표시는 축별 수치와 축별 우수 표시로 하고, 통합 표식은 선택적 전시 정보로만 둔다. 자동 놓아주기·보상·완료 조건에는 연결하지 않는다. 도감 최고 기록 카드는 축별 실제 개체 출처를 남긴다. 통합 표식을 넣을지는 사용자 선호로 남긴다.
