## 4. Claude→Codex 문제 제기와 응답

### I1 [높음/설계 트레이드오프] 포획 확률 연구를 MVP에서 완전히 뺄지, 유료 경로를 차단한 별도 큐로 넣을지
- Claude (조건부): MVP 기본값은 Codex 안(출현 정보 연구만)으로 둔다. 무료 포획 확률 연구는 사용자 선택 항목으로 남기며, 넣을 경우 C 큐·비판매 비용·단축/구독 미적용에 더해 '일반 진행 가속(필드 해금)으로 접근이 빨라지는 간접 연결이 남는다'는 점을 표시하고 정책 비보증 문구를 쓰지 않는다.
  - 비평: 사용자는 R3에서 '포획 관련(포획 확률·출현 정보 등)'을 허용 범위로 명시했다(brief:L28). Codex 안은 위험을 이유로 이를 통째로 뺐지만, Codex가 대안 표에서 지적한 우회 경로(유료 재료가 확률 연구 비용으로 들어감, 유료 단축한 선행 연구가 확률 연구를 앞당김)는 '비판매 비용·독립 선행 조건·단축 불가'로 막을 수 있다고 Codex 스스로 적었다. 공식 문서는 유료 상품이 다른 랜덤 결과의 확률을 바꾸면 사전 수치 설명을 요구하고 간접 구매에도 적용한다(E26, E27). 유료 경로가 아예 없으면 이 규정의 대상이 될 근거가 사라진다. 따라서 '제외'보다 '경로 차단 후 포함'이 사용자 요구를 지키면서 위험을 같은 수준으로 낮춘다. 다만 공식 판정이 없는 해석이므로, 사용자가 가장 안전한 쪽을 원하면 정보 노드만 두는 것도 선택지로 남긴다.
- Codex 응답 (조건부): 무료 확률 연구 자체가 금지된다는 주장은 하지 않는다. R3는 확률·정보를 허용한 것이며 모두 필수라는 뜻은 아니므로 정보만 둔 MVP도 요구 범위에 해당한다. 독립 C 큐는 유용하지만 C1의 필드 해금 경로가 남아 ‘위험이 동일하게 제거됐다’고는 판단할 수 없다. 또한 제안된 일반 진행 연결이 정책상 유료 확률 상품인지도 단정하지 않는다. 현재는 정보만 두는 권장을 유지하고, 확률 연구 포함 여부와 허용할 간접 연결을 사용자 결정으로 남긴다.
  - P3 응답: 무료 확률 연구 자체가 금지된다는 주장은 하지 않는다. R3는 확률·정보를 허용한 것이며 모두 필수라는 뜻은 아니므로 정보만 둔 MVP도 요구 범위에 해당한다. 독립 C 큐는 유용하지만 C1의 필드 해금 경로가 남아 ‘위험이 동일하게 제거됐다’고는 판단할 수 없다. 또한 제안된 일반 진행 연결이 정책상 유료 확률 상품인지도 단정하지 않는다. 현재는 정보만 두는 권장을 유지하고, 확률 연구 포함 여부와 허용할 간접 연결을 사용자 결정으로 남긴다.
  - Codex 출력 원문(토론, 조건부): 무료 확률 연구 자체가 금지된다는 주장은 하지 않는다. ### I2 [중간/설계 트레이드오프] 업데이트 시 생산 연구의 힘을 늘릴 여유를 둘지(1500 상한·1200 사용) vs +12% 고정 후 대체 방식만
- Claude (수용): release별 예산 원장을 둔다. MVP는 +12%(1200bps)를 가안으로 쓰고, 300bps는 '검증되지 않은 후보 여유'로만 표시한다. 시뮬 상한 시험으로 모든 구간이 상한을 만족할 때만 업데이트 예산으로 인정한다. 같은 효과를 다시 연구시키는 대체 방식은 쓰지 않는다.
  - 비평: 사용자는 새 지역·정령이 나오면 연구도 업데이트되기를 원했다(brief:L31). Codex의 대체 방식은 상한을 확실히 지키지만, 새 지역 생산 연구를 해도 이미 +12%인 자원에서는 체감 이득이 0이 되어 '연구할 이유'가 정보 노드뿐이다. R2 상한(10~15%)의 상단은 단순 일정 생산 기준 +17.6%까지 허용하므로(Codex X12의 산식과 같음), +15% 영구 상한 안에서 300bps 여유를 두면 상한을 넘지 않으면서 업데이트마다 작은 생산 이득을 줄 수 있다. 대체 방식은 '지역 한정 효과'에는 유용하므로 함께 쓰는 것을 제안한다.

### C2 [높음/사실] Claude의 가산 공식에서는 direct_bps ≤ idle_bps가 R 중립을 보장하지 않는다. 도감 보너스를 D, 연구 보너스를 A와 I라고 하면 직접 생산 증가율은 A/10000, 방치 증가율은 I/(10000+D)다. D=300, A=I=300이면 R은 약 1.000849배로 증가한다. 현재 최대 3배를 넘는다는 뜻은 아니지만, 정적 보증 규칙은 잘못됐다.

### C3 [중간/사실] ‘단축 구매의 이득 ≤ s_cap−s_natural’은 무연구 시간을 공통 분모로 한 차이에만 해당한다. 자연 연구 대비 상대 단축률의 상한은 동일 표본에서 (s_cap−s_natural)/(1−s_natural)이다. 예를 들어 12%와 7%라면 차이는 5%p지만 자연 연구 대비 단축은 약 5.38%다. 표본별 값의 중앙값끼리 빼는 것도 짝 차이의 중앙값과 일반적으로 같지 않다.
